Documentation

A game engine in C++23, with the editor, asset pipeline and tools to take a game from first scene to shipped build.
Get startedPlay the games

From the editor to a shipped build

A project made in the editor exports to a desktop player, to the browser (WebGPU) and to the Steam Deck.

Rendering and gameplay

Forward PBR with shadows and a full post stack, physics, navigation, audio, skeletal animation with graphs and IK, terrain and vegetation.

Scripting

Gameplay in AngelScript or Luau, and a CSS-styled UI framework for menus and HUDs.

Built to be worked by agents

An MCP host exposes the engine’s reflection, its script API, project operations and play in editor.
